# 16. Translations


Why use Text Message Translations?
 - mainzain a single application insead of separate translated applicaion copies
 - ensure consitent runtime behavior across all languages (by using the same app definition)
 - update translations without republishing the app
 - translations managed centrally
 simplify locilasation with support for xliff, csv and multi-language zip import/export
 - ci/cd workflow with llm-assited translattions generation and automated localisation updates
