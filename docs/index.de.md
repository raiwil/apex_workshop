# Willkommen zum APEX Hands-On Workshop

Dieser Workshop führt Einsteigerinnen und Einsteiger in Oracle APEX ein und zeigt eine breite Auswahl an Möglichkeiten dieses Werkzeugs. Deshalb verzichten wir an einigen Stellen bewusst auf Best Practices, die in Produktionsprojekten sinnvoll sein können. Zum Beispiel kann es vorteilhaft sein, Tabellen nicht direkt aus APEX-Seiten heraus zu verwenden, sondern passende Table APIs einzusetzen. Ebenso kann es produktiv sein, UI Defaults für Datenbankobjekte zu definieren, bevor sie in der Anwendung verwendet werden. Insgesamt kann dieser Workshop nicht alles abdecken und macht aus einem Einsteiger nicht an einem Tag einen Produkt-Guru. Mit APEX ist noch sehr viel mehr möglich.

Viel Spass beim Ausprobieren. Der Workshop darf gerne an Kolleginnen, Kollegen und andere Personen weitergegeben werden, die sich für Oracle APEX interessieren.

Der Workshop kann auch eigenständig ohne Anleitung durchgearbeitet werden. In diesem Fall fehlen jedoch die Erklärungen und Tipps, die oft Aspekte hervorheben, die nicht alle an einem einzelnen Tag behandelt werden können. Und natürlich kann man der Website keine Rückfragen stellen, wie es bei einer Trainerin oder einem Trainer möglich wäre.

Feedback zu diesem Leitfaden ist willkommen. Bitte sendet dieses an rainer.willems@oracle.com. Vielleicht finden Sie Tippfehler, oder etwas funktioniert nicht, weil wir es mit dem aktuellen Release noch nicht erneut getestet haben. Vielleicht fehlt auch ein wichtiger Punkt. Auch allgemeine Rückmeldungen zu diesem Leitfaden sind willkommen.
