# Willkommen zum APEX Hands-On Workshop

Dieser Workshop fuehrt Einsteigerinnen und Einsteiger in Oracle APEX ein und zeigt eine breite Auswahl an Moeglichkeiten dieses Werkzeugs. Deshalb verzichten wir an einigen Stellen bewusst auf Best Practices, die in Produktionsprojekten sinnvoll sein koennen. Zum Beispiel kann es vorteilhaft sein, Tabellen nicht direkt aus APEX-Seiten heraus zu verwenden, sondern passende Table APIs einzusetzen. Ebenso kann es produktiv sein, UI Defaults fuer Datenbankobjekte zu definieren, bevor sie in der Anwendung verwendet werden. Insgesamt kann dieser Workshop nicht alles abdecken und macht aus einem Einsteiger nicht an einem Tag einen Produkt-Guru. Mit APEX ist noch sehr viel mehr moeglich.

Viel Spass beim Ausprobieren. Der Workshop darf gerne an Kolleginnen, Kollegen und andere Personen weitergegeben werden, die sich fuer Oracle APEX interessieren.

Einige Screenshots stammen aus aelteren Releases und koennen bei Verwendung eines anderen Releases leicht anders aussehen.

Der Workshop kann auch eigenstaendig ohne Anleitung durchgearbeitet werden. In diesem Fall fehlen jedoch die Erklaerungen und Tipps, die oft Aspekte hervorheben, die nicht alle an einem einzelnen Tag behandelt werden koennen. Und natuerlich kann man der Website keine Rueckfragen stellen, wie es bei einer Trainerin oder einem Trainer moeglich waere.

Feedback zu diesem Leitfaden ist willkommen. Bitte senden Sie es an rainer.willems@oracle.com. Vielleicht finden Sie Tippfehler, oder etwas funktioniert nicht, weil wir es mit dem aktuellen Release noch nicht erneut getestet haben. Vielleicht fehlt auch ein wichtiger Punkt. Auch allgemeine Rueckmeldungen zu diesem Leitfaden sind willkommen.
