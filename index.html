Task 3: Grant database privileges

If you created the NATIONALPARKS and INCIDENT users in the OCI console as described above, then the following roles and enable script have already been run. If you created the users with a CREATE USER statement or you are using an existing database, then the following should be run for both users.

1

Login to Database Actions

Start by opening Database Actions and signing in with the appropriate user.

2

For the NATIONALPARKS user

Copy and run the SQL privileges below.

-- ADD ROLES
GRANT CONNECT TO NATIONALPARKS;
GRANT RESOURCE TO NATIONALPARKS;
GRANT CREATE SESSION TO NATIONALPARKS;
GRANT CREATE TABLE TO NATIONALPARKS;
GRANT CREATE VIEW TO NATIONALPARKS;
GRANT CREATE PROCEDURE TO NATIONALPARKS;
GRANT CREATE SEQUENCE TO NATIONALPARKS;
GRANT CREATE TRIGGER TO NATIONALPARKS;
3

For the INCIDENT user

Use the same pattern for the second database user.

-- ADD ROLES
GRANT CONNECT TO INCIDENT;
GRANT RESOURCE TO INCIDENT;
GRANT CREATE SESSION TO INCIDENT;
GRANT CREATE TABLE TO INCIDENT;
GRANT CREATE VIEW TO INCIDENT;
GRANT CREATE PROCEDURE TO INCIDENT;
GRANT CREATE SEQUENCE TO INCIDENT;
GRANT CREATE TRIGGER TO INCIDENT;
Note: Run the above statements in SQL Worksheet as a user with the appropriate privileges (for example SYS or a user with ADMIN rights).
