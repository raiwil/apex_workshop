Oracle APEX Workshop Guide

APEX Hands-On Workshop

A static documentation layout populated with the guide's structure, chapter list, and a condensed version of the workshop content.

What this page contains

The sidebar mirrors the workshop structure from the guide, while the main content gives you a ready-made landing page for the chapters, notes, and links.

Based on APEX 24.2.11

Workshop Notes

The guide is presented as a mix of explanations, demonstrations, and exercises. Brown boxes indicate presenter topics, aqua boxes indicate exercises, darker aqua boxes are optional or self-study, and light purple boxes contain tips and notices.

Sequence matters Chapters 2 & 3 create the base application. Later chapters build on that result.
Page numbers APEX page numbers are part of the exercise flow and should match the guide where possible.
Code snippets Red-highlighted snippets in the guide are meant to be copied into SQL or page properties.
Light purple boxes Side notes cover topics like Dark/Light mode, Friendly URLs, JavaScript, and more.

1 Workshop Start – Introduction

Introductory slides explain Oracle Application Express at a high level and set the context for the workshop.

2 APEX – First Steps

  • Learn the main APEX areas: App Builder, SQL Workshop, Team Development, and Gallery.
  • Create EMP and DEPT sample tables from the sample datasets.
  • Build the first application with the wizard, then add a Faceted Search page.
  • Explore the Application Builder, page designer, and light/dark mode options.
CREATE USER example IDENTIFIED BY "password";
GRANT CONNECT, RESOURCE TO example;

3 MyEmployees Application Adjustments

  • Add navigation from the employees report to the employee form.
  • Change date formats in report and form, and replace the department select list with a radio group.
  • Add a list of values for the job item and use validations, read-only rules, and dynamic actions.
  • Understand session state, computations, processes, and branches.

4 Layout – UI in APEX

  • The guide explains themes, template styles, template components, and page-level UI attributes.
  • It shows how to use the Theme Roller, copy report templates, and build custom template components.
  • Object-level CSS classes and JavaScript can be used to tune individual items and regions.

5 Authentication & Authorization

  • Create custom authentication with the EMP table and a simple authentication function.
  • Make the start page public and control menu visibility with authorization schemes.
  • Use authorization to guard pages, buttons, and report columns.
  • Filter report rows by current user and department.

6 Store and show geographical information

  • Create a department form and report, add spatial columns and geocode addresses.
  • Add a map region and refresh it automatically after dialog close.
  • The guide references Oracle eLocation Service for mapping.

7 Integrate RESTful Services

  • Define a REST data source and show population data on the department form.
  • Use REST synchronization for local storage and refresh workflows.
  • The guide also notes nested JSON support and REST source catalogs.

8 Reports

Explains classic reports, interactive reports, interactive grids, cards, faceted search, and smart filters.

9 Calendar

Creates a calendar from an OCCUPANCIES table, tunes the query, and adds color coding via CSS and settings.

10 JavaScript in APEX

Uses the browser console, dynamic actions, event tracing, and JavaScript initialization to extend APEX apps.

11 Charts

Builds a pie chart and bar chart, links them together, and refreshes parts of the page without reloads.

12 Working with Files

Shows file upload, download, image upload/display, and ZIP downloads from a report or button.

13 Data Loading

Uses Data Load Definitions and a generated page to upload files and map them to database tables.

14 Mobile Applications

Covers responsive grids, column toggle reports, reflow reports, PWA setup, and push notifications.

15 Approvals & Workflow

Introduces approvals, human tasks, workflow designer concepts, and the related APEX APIs.

16 Individual Form Handling – Updates over Joins

Demonstrates join-based editing with an Interactive Grid and alternative trigger-based designs.

17 Translations

Adds additional languages using application translations, XLIFF export/import, and globalization settings.

18 Application Lifecycle Management

Shows working copies, merge workflows, and lifecycle handling with Git and SQLcl.

19 AI in APEX

Summarizes AI-assisted development, AI-powered applications, and vector search support in APEX 24.1+.

20 Printing/PDF with APEX

Covers print server options, layout/query integration, and document generation choices.

21 Miscellaneous

Includes JSON documents, master-detail, collections, tree navigation, QR codes, email templates, tabs, automations, plug-ins, and application search.

22 Links & More Learning Content

Ends with learning resources, tutorials, documentation, API references, blogs, office hours, roadmap, and shortcuts.
